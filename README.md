# 光伏卫士 PV-FireGuard

复杂故障场景光伏电站故障诊断与火灾预警一体化智能监测平台（中国科学技术大学 2025 年度“雏鹰基金”项目配套软件）。

## 打开方式
双击 `index.html`，用 Chrome / Edge 打开即可。无需联网、无需安装，所有算法均在浏览器本地运行。

## 功能模块
| 模块 | 内容 |
|---|---|
| 电站数字孪生 | 72 块组件阵列热-电实时仿真；点击注入 7 类故障；5 个复杂故障场景；红外+电弧双通道诊断；四色分级预警；RSD 自动联动；火势蔓延（受风向/可燃物/湿度影响）；事件日志导出 CSV |
| 热斑智能诊断 | 红外原图 → 灰度化 → 卷积特征图（高斯/Sobel/LoG/ΔT）→ 候选区域+NMS → 6 类分类与Ⅰ–Ⅳ级分级；支持导入真实红外图像 |
| 电弧故障诊断 | 200 kHz 直流电流信号；17 维时域/频域/小波特征；浏览器端神经网络训练；混淆矩阵；置换特征重要性；UL 1699B 时效与能量演示 |
| 火灾风险评估 | 故障点热平衡模型推演热失控与引燃时间（有/无防护对比）；可能性×后果风险矩阵；因子贡献可解释；智能处置建议 |
| 诊断报告 | 一键生成报告，打印/导出 PDF、导出 JSON |

## 文件结构
```
index.html          页面
css/style.css       样式
js/util.js          工具与图表
js/dsp.js           信号仿真、FFT、多域特征
js/ml.js            MLP 神经网络（Adam）与特征重要性
js/thermal.js       热失控物理模型与风险融合模型
js/vision.js        红外热像仿真与视觉诊断流水线
js/station.js       电站数字孪生
js/page-*.js        各功能页
js/main.js          路由与启动
```

## 说明
当前版本使用基于物理规律的仿真数据进行演示，模型参数为示意值。接入实验平台（FLIR 红外热像仪、电弧发生装置、数据采集仪）后，可用实测数据替换 `dsp.js` / `vision.js` 中的数据源并重新训练模型。
