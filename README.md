# 光伏卫士 PV-FireGuard

光伏电站电—热融合故障诊断与火灾预警软件模型机（中国科学技术大学 2025 年度“雏鹰基金”项目配套软件）。

> 以电—热融合为核心，实现光伏直流侧故障诊断、火灾预警与全过程事件追溯。

## 打开方式
双击 `index.html`，用 Chrome / Edge 打开即可。无需联网、无需安装，所有算法均在浏览器本地运行。

## 五大功能模块
| 模块 | 内容 | 输出 |
|---|---|---|
| ① 电站可视化与状态监测 | 建立设备与测点关联（组串 ↔ 汇流箱/MPPT ↔ CT/VT/TC/IR 测点），展示电压、电流、温度和在线状态；72 块组件阵列热-电仿真、故障注入与 5 个复杂故障场景 | 电站总览、异常分布与历史趋势 |
| ② 热异常与热斑诊断 | 分析组件、连接器等部位的热点、温差及温升过程；红外热像 → 灰度化 → 卷积特征 → 候选区域 + NMS → 分类、部位定位与分级 | 热异常位置、特征参数与待复核结果 |
| ③ 电弧故障诊断（实测数据） | 使用电弧实验平台实测数据（100 kHz，直流侧 + 交流侧电流，5 类负载 × 无弧/直流侧电弧/交流侧电弧）。先核验采样要求，再提取双通道 34 维多域特征由神经网络判别（按记录划分训练/测试），连续窗确认；支持无弧→电弧拼接回放 | 异常时段、关联回路与诊断证据 |
| ④ 电—热融合风险评估与预警 | 关联电气异常与热状态演化，依据 6 项验证判据（C1 温差、C2 温升速率、C3 故障点温度、C4 电弧特征、C5 电—热同回路关联、C6 环境加剧）分级；热失控推演与多因素风险指数作参考 | 风险等级、触发原因与处置优先级 |
| ⑤ 事件管理与诊断报告 | 事件自动建档并留存电—热证据时序；同步回放；确认 → 排查 → 处理 → 复核闭环 | 事件档案、处理状态与可导出报告（CSV / JSON / PDF） |

## 后台数据支撑层
多源数据接入与设备映射 · 时间同步与数据质量检查 · 数据预处理与特征管理 · 历史存储与事件归档 · 算法模型与预警判据管理 · 权限、日志与运行维护。
页面中可模拟测点通信中断/时钟漂移、在线修改预警判据、切换用户角色（管理员 / 运维工程师 / 只读访客），所有操作写入审计日志。

## 实测电弧数据（5-30.rar）
原始数据：29 个 CSV（约 3 GB），DAQ 采样率 100 kHz，通道0 = 交流侧电流、通道1 = 直流侧电流；
负载类型：阻性、感性、阻感、电子开关类、混合；工况：无电弧 / 直流侧电弧 / 交流侧电弧（文件名即标签）。

浏览器端无法直接读取 3 GB CSV，故先预处理为约 1.9 MB 的内嵌数据包：
1. 解析 GBK 表头与文件名标签；按 ADC 步长（≈4.93 mV）还原为 int16，近似无损；
2. 1024 点（10.24 ms）分窗，剔除无电流窗口；
3. 每条记录在 4 个位置各取 10 个连续窗（共 1160 窗），并保存每 0.1 s 的全时段统计概览；
4. 差分 + gzip + base64 编码，浏览器用 `DecompressionStream` 解压；
5. 按记录划分：序号 1 训练、序号 ≥2 测试，避免同一记录窗口泄漏到测试集。

重新生成：
```
"C:\Program Files\WinRAR\UnRAR.exe" x 5-30.rar <临时目录>\
python tools/preprocess_arc.py <临时目录>\5-30 data/arc-real.js
```
在线监测（模块①）中各组串的电流信号即从这些实测窗口回放：正常组串取同负载无弧记录，注入电弧故障时取直流侧电弧记录，逆变器干扰取电子开关类负载无弧记录。
电弧诊断页的单窗诊断与回放使用“评估模型”（只用训练集记录训练）；在线监测使用全部记录训练的“部署模型”。

## 说明
电弧诊断部分使用上述实测数据；红外热像、热平衡模型与风险评估部分仍为基于物理规律的仿真数据，判据阈值为示意值。接入 FLIR 红外热像仪等设备后，可用实测数据替换 `vision.js` 中的数据源，并在“后台数据支撑层”中完成判据验证与调整。
